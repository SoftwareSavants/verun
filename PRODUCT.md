# Verun

## Register
Product: a desktop workspace for developers coordinating coding agents across repositories and tasks.

## Users and purpose
Developers work across multiple projects and agent sessions, including detached windows. They need to find related work, hide unrelated projects, and notice tasks awaiting input without losing their place.

## Design principles
Keep the interface compact and quiet. Prefer familiar desktop controls, concise labels, and progressive disclosure. Preserve horizontal space. Use the existing custom Select for choices. Show project context wherever a task can be opened independently. Separate agent activity from task completion; idle is not done. The live board groups tasks automatically and never implies that moving a card starts, stops, or archives work.

## References and anti-references
The user favors Codex's composer-based task creation, a combined harness/model picker, small badge-sized controls, and minimal repeated labels. Avoid nested sidebar indentation, redundant headings, and native HTML selects.
